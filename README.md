# 전기기능사 학습실

사용자의 공개 동의에 따라 1일차부터 7일차 2회차까지 10개 학습 기록을 기본 제공합니다. 노션 원문 주소와 접근 정보는 공개 데이터에 포함하지 않습니다.

## 공개되는 범위

기본 학습 이력에는 진도, 학습 내용, 기록에 있는 제출 답안·채점 결과·오답 원인·보충 내용이 포함됩니다. 이 데이터는 공개 저장소와 웹앱에서 누구나 볼 수 있습니다.

웹앱에서 이후 입력하는 답안·메모·진도는 해당 기기의 브라우저 localStorage에 저장되며 자동으로 공개 저장소에 올라가지 않습니다. 다른 기기와 자동으로 동기화되지 않습니다. 공개 기준 기록을 갱신하려면 저장소의 기본 데이터를 별도로 업데이트해야 합니다.

## 실행과 사용

설치·빌드 없이 index.html을 엽니다. GitHub Pages는 main 브랜치의 루트 폴더를 게시합니다.

처음 접속하면 공개 학습 이력을 자동으로 불러옵니다. 기존 브라우저 기록이 있으면 병합하며, 기존 제출 답안과 메모를 보존하고 중복 회차를 추가하지 않습니다. 학습 계획 화면에서 JSON 백업·가져오기를 사용할 수 있습니다.

## 기능

- 회차별 개념·예제·문제·제출 답안·채점·오답·보충 기록
- 확인된 최초·보충 정답률 별도 집계
- 복습 우선순위와 미완료 항목, 일반 텍스트 요약
- 확인되지 않은 페이지와 성적은 미확인 유지

자동 채점은 정규화된 텍스트 일치 비교입니다. 서술형 의미와 단위는 직접 검토할 수 있습니다. 채팅·노션 실시간 자동 동기화는 지원하지 않습니다.
