# 전기기능사 학습실

다산에듀 2026 속전속결 교재 목차를 바탕으로 진도·회차·오답·복습을 기록하는 정적 웹앱입니다.

## 개인정보

이 공개 저장소에는 노션 원문, 과거 답안·성적, 개인 식별 정보가 포함되지 않습니다. 7일차 2회차용 빈 템플릿만 들어 있습니다. 이전 기록은 개인 JSON 백업으로 복원합니다.

학습 기록은 브라우저 localStorage에 저장됩니다. 기기 간 자동 동기화와 서버 계정 저장은 지원하지 않습니다. 브라우저 데이터를 삭제하기 전에 반드시 학습 계획 화면에서 JSON 백업을 내려받으세요. 복원한 데이터는 서버로 전송되지 않습니다.

## 실행

`index.html`을 브라우저에서 열거나 GitHub Pages로 게시합니다. 설치·빌드가 필요하지 않습니다.

GitHub Pages 설정: Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save.

## 학습 기록 복원

1. 웹앱의 학습 계획 메뉴를 엽니다.
2. 데이터 백업·복원에서 개인 JSON 백업을 선택합니다.
3. 복원을 확인하고 상단의 브라우저 저장 상태를 확인합니다.

## 기능과 한계

- 회차별 개념·계산 예제·문항·제출 답안·채점·원인·보충 기록
- 최초/보충 정답률 별도 집계, 같은 개념 태그의 반복 오답 집계
- 미완료 복습, 우선순위, 주간 계획, 미니시험
- 노션에 복사하는 일반 텍스트 요약
- 미확인 페이지·진도 표시, 공식 시험일 미확정 유지

자동 채점은 정규화한 텍스트 일치 비교입니다. 서술형 의미·단위·동의어 판단은 직접 수정할 수 있습니다. 노션 실시간 동기화는 포함하지 않습니다.

이 저장소는 Sites와 별개의 정적 배포 버전입니다. Sites의 계정 저장·인증을 대체하지 않습니다.
